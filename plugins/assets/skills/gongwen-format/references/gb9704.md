# GB/T 9704-2012《党政机关公文格式》条款要点（排版用）

> 依据 GB/T 9704-2012 标准正文（2012-06-29 发布）。以国家正式文本为最终依据；本文覆盖公文版式核心参数。

## 1. 公文用纸与版面

- 用纸：A4 型（210mm × 297mm），60~80 g/m² 胶版印刷纸或复印纸。
- 天头（上白边）37mm±1mm，订口（左白边）28mm±1mm，版心 156mm × 225mm（即下白边 35mm、右白边 26mm）。
- 每面排 22 行、每行排 28 字，撑满版心。
- 默认字体：各要素一般用 3 号仿宋体字；文字颜色均为黑色（红头、印章、红色分隔线除外）。
- 行高定义：一行 = 一个汉字高度 + 3 号汉字高度的 7/8（实际排版用固定行距 28~29 磅近似）。
- 结构三分：版头（首页红色分隔线以上）、主体（红色分隔线以下至末页首条分隔线以上）、版记（末页首条分隔线以下、末条分隔线以上）。页码位于版心外。

## 2. 版头要素（7.2）

| 要素 | 编排 |
|---|---|
| 份号（7.2.1） | 6 位 3 号阿拉伯数字，顶格，版心左上角第一行 |
| 密级和保密期限（7.2.2） | 3 号黑体字，顶格，版心左上角第二行；保密期限数字用阿拉伯数字（如"机密★5年"） |
| 紧急程度（7.2.3） | 3 号黑体字，顶格，版心左上角；与份号、密级同时标注时按"份号→密级→紧急程度"自上而下分行 |
| 发文机关标志（7.2.4） | 发文机关全称或规范化简称+"文件"二字（也可只用全称/简称）；居中排布，**上边缘至版心上边缘为 35mm**；推荐小标宋体字，红色，以醒目、美观、庄重为原则 |
| 发文字号（7.2.5） | 编排在发文机关标志**下空二行**位置，**居中排布**；年份、顺序号用阿拉伯数字，年份标全称并用六角括号"〔〕"括入；顺序号不加"第"字、不编虚位（1 不编为 01），数字后加"号"字。**上行文的发文字号居左空一字编排，与最后一个签发人姓名处在同一行** |
| 签发人（7.2.6） | 由"签发人"三字 + 全角冒号 + 签发人姓名组成，**居右空一字**，编排在发文机关标志下空二行位置；"签发人"三字用 **3 号仿宋体字**，姓名用 **3 号楷体字**。多个签发人：按发文机关排列顺序从左到右、自上而下依次均匀编排，一般每行排两个姓名，回行与上一行第一个姓名对齐 |
| 版头分隔线（7.2.7） | 发文字号之下 **4mm** 处居中印一条与版心等宽的**红色分隔线** |

- 联合行文：联署机关名称主办机关在前；"文件"二字置于发文机关名称右侧，以联署名称为准上下居中排布。

## 3. 主体要素（7.3）

### 3.1 标题（7.3.1）
- 一般用 **2 号小标宋体字**，编排于**红色分隔线下空二行**位置，分一行或多行居中排布。
- 回行时：词意完整、排列对称、长短适宜、间距恰当；标题排列使用**梯形或菱形**。
- 标题中除法规、规章名称加书名号外，一般不加标点符号。

### 3.2 主送机关（7.3.2）
- 编排于标题下空一行位置，**居左顶格**，回行时仍顶格。
- 最后一个机关名称后标全角冒号"："。
- 首页不能显示正文时，主送机关移至版记（标注方法见 7.4.2）。

### 3.3 正文（7.3.3）
- 首页必须显示正文。一般用 **3 号仿宋体字**，编排于主送机关名称下一行。
- **每个自然段左空二字（首行缩进 2 字符），回行顶格**。
- 行距：固定值 28~29 磅（22 行/页，撑满版心）。
- 文中结构层次序数依次用"一、" "（一）" "1." "（1）"标注：
  - 第一层"一、"——**黑体字**
  - 第二层"（一）"——**楷体字**
  - 第三层"1."——**仿宋体字**
  - 第四层"（1）"——**仿宋体字**
- 不得越级使用。

### 3.4 附件说明（7.3.4）
- 在正文下空一行**左空二字**编排"附件"二字，后标全角冒号和附件名称。
- 多个附件用阿拉伯数字标顺序号：如"附件：1. XXXXX"；**附件名称后不加标点符号**。
- 附件名称较长需回行时，与上一行附件名称首字对齐。

### 3.5 发文机关署名、成文日期和印章（7.3.5）
- **加盖印章的公文（7.3.5.1）**：成文日期一般**右空四字**编排；单一机关行文时，在成文日期之上、**以成文日期为准居中编排发文机关署名**；印章端正、居中下压署名和成文日期，印章顶端上距正文（或附件说明）一行之内。
- **不加盖印章的公文（7.3.5.2）**：正文（或附件说明）下空一行**右空二字**编排发文机关署名；署名下一行编排成文日期，**成文日期首字比署名首字右移二字**；如成文日期长于署名，成文日期仍右空二字，相应增加署名右空字数。
- **加盖签发人签名章（7.3.5.3）**：正文下空二行右空四字加盖签名章（红色），签名章左空二字标注签发人职务全称，以签名章为准上下居中；签名章下空一行右空四字编排成文日期。
- **成文日期数字（7.3.5.4）**：用阿拉伯数字将年月日标全，年份标全称，**月、日不编虚位**（1 不编为 01）。
- 特殊情况（7.3.5.5）：空白处容不下印章/日期时，可调整行距、字距。

### 3.6 附注（7.3.6）
- 居**左空二字加圆括号**编排在成文日期下一行（如"（此件公开发布）"）。

### 3.7 附件（7.3.7）
- 附件**另面编排**，在版记之前，与正文一起装订。
- "附件"二字及顺序号用 **3 号黑体字顶格**编排在版心左上角第一行（如"附件1"）。
- 附件标题**居中**编排在版心第三行。
- 附件顺序号和标题与附件说明一致；附件格式要求同正文。
- 不能一起装订时，在附件左上角第一行顶格编排发文字号，其后标注"附件"二字及顺序号。

## 4. 版记（7.4）

- **分隔线（7.4.1）**：与版心等宽；**首条、末条用粗线（推荐 0.35mm ≈ 1 磅），中间用细线（推荐 0.25mm ≈ 0.75 磅）**；首条位于版记第一个要素之上，末条与公文最后一面版心下边缘重合。
- **抄送机关（7.4.2）**：**4 号仿宋体字**，在印发机关和印发日期之上一行，**左右各空一字**编排；"抄送"二字后加全角冒号和机关名称，回行时与冒号后首字对齐，最后一个机关名称后标句号。主送机关移至版记时改标"主送"，方法同抄送；既有主送又有抄送时，主送置于抄送上一行，之间不加分隔线。
- **印发机关和印发日期（7.4.3）**：**4 号仿宋体字**，编排在末条分隔线之上；**印发机关左空一字，印发日期右空一字**，阿拉伯数字标全年月日（月日不编虚位），**日期后加"印发"二字**（即整行形如"×××办公室　2026年9月7日印发"）。
- 版记中如有其他要素，应当将其与印发机关和印发日期用一条细分隔线隔开。
- 版记位于公文最后一面；版记页前有空白页的，空白页和版记页**均不编排页码**。

## 5. 页码（7.5）

- 一般用 **4 号半角宋体阿拉伯数字**，编排在**公文版心下边缘之下，一字线上距版心下边缘 7mm**；数字左右各放一条一字线（如"— 1 —"）。
- **单页码居右空一字，双页码居左空一字**。
- 附件与正文一起装订时，页码连续编排。

## 6. 横排表格（7.6）

- A4 表格横排时，页码位置与公文其他页码一致；单页码表头在订口一边，双页码表头在切口一边。

## 7. 特定格式（10）

| 格式 | 标志与版式 |
|---|---|
| 信函格式（10.1） | 发文机关标志用全称或简称，居中，**上边缘至上页边 30mm**，红色小标宋；标志下 4mm 印红色双线（上粗下细），距下页边 20mm 印红色双线（上细下粗），线长 170mm 居中；发文字号顶格居版心右边缘第一条双线下；标题居中，与其上最后要素相距二行；首页不显示页码；版记不加印发机关日期与分隔线，位于最后一面版心内最下方 |
| 命令（令）格式（10.2） | 标志 = 全称 +"命令"/"令"，居中，**上边缘至版心上边缘 20mm**，红色小标宋；标志下空二行居中编排令号，令号下空二行编排正文 |
| 纪要格式（10.3） | 标志 = "××××纪要"，居中，**上边缘至版心上边缘 35mm**，红色小标宋；出席人员名单：正文下空一行左空二字标"出席"（3 号黑体）+ 全角冒号，冒号后用 3 号仿宋标出席人单位、姓名，回行与冒号后首字对齐；"请假""列席"同法依次另起一行 |

## 8. 文种与行文规则（提示）

- 15 种法定文种：决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要。
- 请示：一文一事，主送一个上级机关，不得抄送下级机关。
- 报告：不得夹带请示事项。
- 函：不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项。
- 纪要：记载主要精神和议定事项，经签发后生效。

## 9. 联合行文

- 联署机关名称并列，主办机关在前；发文字号用主办机关的。
- 联合行文只注明主办机关签发人（如需）。
- 各机关印章与署名一一对应、互不相交或相切，每排印章两端不得超出版心。

## 10. 印章（电子稿提示）

- 印章用红色，不得出现空白印章；电子公文使用红色电子印章。
- 印章端正、居中下压发文机关署名和成文日期，使署名和日期居印章中心偏下位置（骑年盖月）。
