# 公文格式排版（GB/T 9704-2012）

按《党政机关公文格式》国家标准（GB/T 9704-2012）排版公文：A4 页面与版心、版头/主体/版记三段结构、标准字体字号（小标宋标题、仿宋正文、黑体/楷体层次序号）、附件另面编排、版记与页码编排。

## 使用方式

### A. 生成标准 .docx（首选，确定性排版）

按 `scripts/gen_gongwen.py` 顶部的 JSON 说明组织公文内容，保存为 `doc.json`（UTF-8），执行：

```bash
python scripts/gen_gongwen.py doc.json 输出文件名.docx
```

脚本自动完成：页面设置（A4，上 3.7 / 下 3.5 / 左 2.8 / 右 2.6 cm，版心 156×225mm）、发文机关标志（红头，上边缘距版心上边缘 35mm）、发文字号（下行文居中/上行文左空一字）与签发人居右空一字、发文字号下 4mm 红色分隔线、标题 2 号小标宋（分隔线下空二行）居中、正文 3 号仿宋 + 固定行距、层次序号字体（黑体/楷体/仿宋）、附件说明、落款（盖章式：以成文日期为准居中署名 + 日期右空四字；不盖章式：右空二字 + 日期右移二字）、附件另面（"附件1" 3 号黑体顶格 + 标题居中）、版记（抄送/印发 4 号仿宋，首条/末条粗线 1 磅、中间细线 0.75 磅，末线与版心下边缘重合）、页码（— 1 —，4 号宋体，单页右空一字/双页左空一字，上距版心下边缘 7mm）。

字体自动降级：方正小标宋简体 → 华文中宋（STZhongsong）→ 宋体加粗；仿宋 → 华文仿宋（STFangsong）。发生降级时终端会提示，提醒用户在 Word 中核对字体。

### B. 排版/校对规范清单

用户只要规范、要在 Word 手工排版或要校对现有公文时：对照 `references/gb9704.md` 条款输出要求，并逐条检查 `references/common-mistakes.md` 的错误清单。

## 核心规范速查（条款依据详见 references/gb9704.md）

## 校验清单（生成后逐项确认）

1. 页面：A4，上 3.7 / 下 3.5 / 左 2.8 / 右 2.6 cm
2. 红头：红色，居中，距版心上边缘 35mm
3. 发文字号：六角括号〔2026〕，3 号宋体，序号不编虚位
4. 标题：小标宋二号，分隔线下空二行，居中，折行词意完整
5. 主送机关：顶格，全角冒号
6. 正文：仿宋三号，固定行距，首行左空二字、回行顶格
7. 层次序号：一、（黑体）→（一）（楷体）→1.（仿宋）→（1）（仿宋），不越级
8. 成文日期：4 位年份，月日不编虚位（2026年9月7日）
9. 附件说明在正文之后、落款之前；附件另面编排
10. 落款位置：盖章式（署名居中于日期上方 + 日期右空四字）或不盖章式（右空二字体系）
11. 版记：4 号仿宋；抄送末尾句号；印发机关左空一字、印发日期右空一字（后加"印发"二字）；首条/末条粗线 1 磅、中间细线 0.75 磅，末线与版心下边缘重合
12. 页码：— 1 —，单页右空一字，不编虚位
13. 印章提示：电子稿应在成文日期上方加盖（红色）电子印章，不得空白章

完整条款：`references/gb9704.md`；字体字号映射与页面参数：`references/font-table.md`；常见错误：`references/common-mistakes.md`。
