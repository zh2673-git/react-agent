PROMPT 具名模板仍由 REPL /prompt 管理；预算耗尽以 K508 收敛（时长/token 分开提示），子代理继承衰减后的剩余预算；上下文超限以 CONTEXT_OVERFLOW 收敛（发送前逐级收紧 → 仍超限即失败，provider 终审超限则降级重试一次）。

通用外部通道配置（如 IM 网关等消费方）。JSON 对象形式，每个键为一个通道段；值仅接受字符串/布尔/数字。敏感字段（client_secret/token/key/api_key/password）回显为掩码，留空字符串或 null 表示不修改已有值。保存后由消费方下次读取生效。

这是宿主通用扩展点，不绑定具体平台；具体字段名由消费方（网关）定义。

▣ 新建窗口（独立实例）

新窗口 = 独立 host 进程：独立会话/回滚/配置，端口自动分配（8711 起）；实例名自动取文件夹名（同名窗口已开着就直接复用）。首次建窗自动继承当前窗口的模型配置（api_key 免重配）。数据存于代码根 .instances/，不影响目标项目目录。子窗口按需恢复：主窗口重启后不自动拉起，在下表点「启动」即按原工作区复活（换新端口，会话保留）。
