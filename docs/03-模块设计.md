# 03 模块设计

> 模块划分、全部线契约、执行流说明与环境变量汇总。契约一经实施即为冻结项，后续只增不改。

## 1. 模块划分与注册顺序

| 顺序 | 插件 | capability | 对 agent-loop 依赖 |
|---|---|---|---|
| 1 | memory（TS guest） | `memory.session` + `session.trace` | 硬 |
| 2 | llm-adapter（Python guest） | `llm.chat` | 硬 |
| 3 | tools（Python guest） | `tools.exec` | 硬 |
| 4 | assets（Python guest） | `assets.registry` | **软**（失败静默降级） |
| 5 | agent-loop（Rust InProcess） | `agent.chat` | — |

前端（Phase 3-2）：host 级 `trait Frontend` 两实现——`ReplFrontend`（默认）/ `WebFrontend`（`REACT_FRONTEND=web`）。前端是入口组件而非 guest 能力（网关需调 `agent.chat` + `session.trace`，guest 不可互调；切换必伴随重启，热插拔无收益）。

## 2. 线契约全集

### 2.1 agent-loop（`agent.chat`）
- req：`{"op":"chat","session_id":str,"user_text":str}`
- resp：`{"ok":true,"answer":str,"rounds":int,"steps":[{"round":int,"tool":str,"ms":int}],"session_id":str}` | `{"ok":false,"error":{"code","message"}}`
- 变更：新增 `steps`（逐轮工具调用观测，Phase 1 只回传不持久化）

### 2.2 llm-adapter（`llm.chat`，不变）
- req：`{"op":"chat","provider"?:"openai"|"anthropic"|"ollama"|"mock","messages":[Msg],"tools"?:[ToolSpec]}`
- resp：`{"ok":true,"content":str|null,"tool_calls":[{"id","name","arguments":object}],"model":str,"finish_reason":str}`
- Msg / ToolSpec 定义见 README「Contracts」，逐字不变

### 2.3 tools（`tools.exec`）
- `{"op":"list"}` → `{"ok":true,"tools":[ToolSpec]}`（返回生产级 7 件，受 `TOOLS_ENABLED` 裁剪）
- `{"op":"call","name":str,"args":object}` → `{"ok":true,"result":any}` | `{"ok":false,"error":{"code","message","field"?}}`
- 变更：工具集替换；错误升级为**字段级**（哪个参数错、合法值是什么、下一步怎么改）

### 2.4 assets（`assets.registry`，**新增**）
- `{"op":"skills.list"}` → `{"ok":true,"skills":[{"name","description"}]}`
- `{"op":"skills.load","name":str}` → `{"ok":true,"content":str}` | `{"ok":false,"error":{...}}`
- `{"op":"prompts.list"}` → `{"ok":true,"prompts":[{"name","description"}]}`
- `{"op":"prompts.get","name":str}` → `{"ok":true,"content":str}`

### 2.5 memory（`memory.session`）
- append / get(limit) / clear，见 README
- `{"op":"summarize","session_id":str,"summary":str,"keep_last"?:int=10}` → `{"ok":true,"count":int}`（Phase 2-2 上下文压缩：历史替换为 [压缩标记] + 最近 keep_last 条；孤儿 tool 消息防撕裂——切片开头连续 tool 消息被丢弃）

### 2.6 memory（`session.trace`，Phase 3-1 事件日志）
- `{"op":"trace.append","session_id":str,"events":[Event...]}` → `{"ok":true,"count":int}`（**只追加**，不可变）
- `{"op":"trace.read","session_id":str,"after"?:int=0}` → `{"ok":true,"events":[Event],"next":int}`（增量读取）
- Event = 任意 JSON 对象（建议 `{type, ts, ...}`）；存储：`<MEMORY_DATA_DIR>/traces/<session>.jsonl`
- 事件类型全集（agent-loop 发射）：`user` / `assistant` / `tool_call` / `tool_result`（结果截断 2000 字符）/ `compaction` / `subagent` / `error`
- 与 memory 的边界：记忆=模型上下文（可压缩重组，面向模型）；事件日志=系统事实（只追加不可变，面向审计/恢复/UI 重放）

### 2.7 web 网关（Phase 3-2，host 级 HTTP，非插件）
- `GET /` → dsh 风格单页（编译期内嵌 `web.html`）
- `GET /api/events?session=&after=` → SSE：从 after 起增量轮询 `trace.read` 逐事件推送；连接建立即从 0 重放全量（**刷新恢复=日志重放**），300ms 轮询 + 15s 心跳注释行
- `POST /api/chat` body `{"session_id":str,"message":str}` → 阻塞至 agent 收敛，回 agent.chat 响应；400=字段级错误（body 非法/缺 session_id/缺 message）
- 其余路由 404；极简手写 HTTP（tokio TcpListener，零 web 框架依赖）

## 3. 保留名空间（agent-loop 路由规则）

| 保留工具名 | 路由目标 | 说明 |
|---|---|---|
| `load_skill` | assets `skills.load`（参数 `{"name":str}`） | 不出现在 tools.list；catalog 随系统提示词注入，模型按描述主动调用 |
| `task`（Phase 3-3） | **子代理**：以 `{parent}#sub-{n}` 全新 session 复用 agent.chat 全链路（参数 `{"task":str}`） | 不出现在 tools.list，但随 tools 声明传给模型（严格函数调用协议可见可调）；**深度防嵌套**（depth≥2 拒绝，DepthGuard RAII）；仅回传最终答案，子会话独立记忆+事件日志（subagent 事件关联可追溯） |

规则：保留名优先于 tools 分发；assets 不可用时 `load_skill` 调用返回字段级错误（不中断循环）；子代理内再调 `task` 返回字段级拒绝（不中断子代理循环）。

## 4. 执行流说明

1. chat 进入：用户消息写 memory → 拉历史（`HISTORY_LIMIT` 截断）→ **上下文压缩（可选，Phase 2-2）**：历史 > `COMPACT_TRIGGER`（默认 40，0=禁用）时旧史（除最近 `COMPACT_KEEP`=10 条）交 LLM 摘要并经 `summarize` op 持久化，任何失败降级为不压缩 → 拉 tools.list → 拉 skills.list（软）；
2. 系统提示词 = 内置缺省（或 prompts 覆盖链）+「可用技能」附录（name+description，~100 token/个）；
3. 状态机循环：plan（llm.chat）→ 无 tool_calls 则收敛；有则逐个 act（`load_skill` 走保留名路由，其余走 tools.exec）→ 观察（结果回写 memory + 拼入上下文）→ 回跳；
4. 末轮去工具强制收敛；`steps` 全程记录。

## 5. 环境变量汇总（新增部分）

| 变量 | 默认 | 说明 |
|---|---|---|
| `WORKSPACE_ROOT` | 进程 cwd | 文件工具越界拦截根（realpath 前缀校验） |
| `TOOLS_ENABLED` | 全开 | 逗号分隔白名单，如 `read_file,write_file,bash` |
| `SEARCH_REGION` | `cn` | cn / global——区域选路（cn：Bing→搜狗→百度零 key 直连；global：ddgs→DDG→Bing） |
| `SEARCH_BACKEND` | 自动 | 强制指定引擎：bing / sogou / baidu / ddgs / duckduckgo / bocha / baidu_ai / tavily |
| `BOCHA_API_KEY` / `BAIDU_API_KEY` / `TAVILY_API_KEY` | — | 可选升级后端（百度千帆每日 100 次免费；Tavily 每月 1000 次免费） |
| `SKILLS_DIR` / `PROMPTS_DIR` | `<workspace>/plugins/assets/{skills,prompts}` | 资产目录 |
| `AGENT_SYSTEM_PROMPT` / `SYSTEM.md` / `PROMPT` | 内置缺省 | 提示词覆盖优先级：env > SYSTEM.md > 具名模板 > 内置 |
| `HISTORY_LIMIT` | 不限 | 每轮回传历史条数上限 |
| `COMPACT_TRIGGER` / `COMPACT_KEEP` | 40 / 10 | 上下文压缩触发阈值（0=禁用）/ 保留最近条数 |
| `BASH_SANDBOX` | `on` | on=sandbox-run 受限令牌助手（探测失败 fail-closed 移除 bash，绝不静默直跑）；off=显式豁免直跑 |
| `REACT_FRONTEND` | `repl` | 前端选择：repl / web（Phase 3-2） |
| `WEB_ADDR` | `127.0.0.1:8710` | web 网关监听地址 |

既有变量（LLM_PROVIDER 系、MAX_ROUNDS、SESSION_ID 等）不变，见 README。
